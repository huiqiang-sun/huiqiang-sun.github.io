Prisma-World

Camera-Controllable Multi-Agent Video Generation with Variable Agent Number

Prisma-World generates multiple controllable agent videos together in one denoising process, preserving cross-view consistency while supporting variable agent counts, player interaction, open-domain scenes, and minimap guidance.

Core idea

Generate many views as one shared world.

Independent video generation can create different versions of the same building, road, or object across agents. Prisma-World treats multi-agent generation as a single geometry-aware denoising problem, so overlapping viewpoints can negotiate a consistent scene state during generation.
